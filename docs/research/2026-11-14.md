  by hosts. No new Svelte advisory since 2026-11-07 found.
- **Test tooling** (`web/test/check.sh`, installed per job, not shipped):
  it pins `vite@6` and `vite-plugin-svelte@5`, takes `svelte@5` and `jsdom`
  unpinned. Reported: Vite 8.3.x current with 6.4.x still maintained
  ([Vue newsletter](https://dev.to/aloisseckar/new-in-vue-november-2026-4l2m));
  SvelteKit 3 shipped ([svelte.dev](https://svelte.dev/blog/sveltekit-3-is-here));
  jsdom 30.1.3 bump seen. Nothing breaks the pins. Hosts on Vite 8 / newer
  vite-plugin-svelte are not covered by the host build check — a possible
